# Local datasets

The notebook expects the MovieLens 1M files here:

```text
datasets/movie_lens/
  ratings.dat
  users.dat
  movies.dat
  README
```

Obtain MovieLens 1M from GroupLens: https://grouplens.org/datasets/movielens/1m/

Extract the archive and place its files in `datasets/movie_lens/`. Read the dataset's included README for its usage and citation terms. Dataset files are ignored by Git; this setup guide is tracked.
